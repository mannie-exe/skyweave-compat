# Skyweave: Compatibility Patches 0.28.0

Keep rivers continuous across island cavities, distinguish real water mouths from void outlets, and add bounded structure discovery. Minecraft remains 1.21.1, Sky Archipelago 1.4 and Dynamic Waters 13.1.0.

- Protect supported river beds before subtracting NOISE/HOLLOW interiors. Retain the original rock shell without constructing foundations into empty sky.
- Terminate drainage at its own island rim or actual local water level. Empty sky no longer sends river mouths toward global sea level or across detached fragments. Dynamic Waters density remains HIGH.
- Use the water cell's biome for generation and precipitation freezing. Preserve genuine cold-biome snow, cold surface layers and running-water ice rules.
- Give skylights seeded oval/warped outlines and bounded connections to HOLLOW interiors. NOISE skylights default off; side entrances remain independent. Radius, warp and aspect variation are editable in the existing settings page.
- Default falling-perimeter lagoon selection to zero, retaining 25% coastal and 75% native treatment among admitted lagoons. Explicit opt-in remains available.
- Add `/skyweavecompat structures search <radius> family=…` or `structure=<id|#tag>`, plus status/page/cancel. Searches continue automatically within configurable limits and return verified starts with suggested teleports. Limited searches report partial results, never false absence or a proved nearest result.

Structure search can save early chunk metadata. Supported random-spread grids are enumerated; unsupported placements and omitted unplaced IDs are reported. Historical starts without an active placement grid are outside this command's coverage. Vanilla `/locate` remains synchronous; use the bounded command for broad cold searches. Search limits live in `config/skyweave/skyweave_compat-search.json` and require restart, without changing terrain identity.

**A fresh world is required.** Terrain identity is now `islands_v1-skyarch-1.4-5`, with `island_watersheds_v4` drainage. Existing saves are not silently converted. Legacy interior files receive the new skylight defaults while preserving their explicit existing settings.

See [verification](https://github.com/mannie-exe/skyweave-compat/blob/v0.28.0/docs/development/verification.md) for exact native checks, tested boundaries and remaining limitations.
