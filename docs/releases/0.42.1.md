# Skyweave: Compatibility Patches 0.42.1

Install [re:form 0.2.0](https://github.com/mannie-exe/reform/releases/tag/v0.2.0) with Minecraft 1.21.1, Java 21, and NeoForge 21.1.265. Existing saved generation identity and configuration filenames remain unchanged.

## Kaleidoscope Cookery

Add an independently optional repair for Cookery 1.6.0's millstone automation handler. Simulated insertion now reports the same bounded acceptance as execution, including offers above eight items. Both paths preserve caller-owned stacks and item components. Occupied input is retained even when its progress is zero, and invalid slots are refused. Component-defined stack limits are respected.

The adaptation retains native recipes, recipe events, processing time, output, and direct player insertion. It defaults on for the exact supported runtime. Disable `kaleidoscope_cookery.millstone_insertion` in the startup switches or under Machines → Kaleidoscope Cookery → Millstone insertion, then restart, to use upstream behavior. Cookery remains optional.

Native controls reproduce the original handler defects and exercise the repaired capability, native insertion helper, refusal states, and complete wheat-to-flour processing. The upstream AE2 duplication report motivated this repair; no AE2 network or whole-pack exploit reproduction is claimed. See [adapter maintenance](../development/adapters.md#cookery-millstone-insertion) and [verification](../development/verification.md) for update procedures, exact artifacts, and limits.
