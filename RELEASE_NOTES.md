# Skyweave: Compatibility Patches 0.41.0

Use **re:form 0.1.0** on both installed sides, with Minecraft 1.21.1, Java 21 and NeoForge 21.1.265. Publish/install the library before updating Compat; it is a separate required dependency.

- Open one shared configuration catalog from Configure, organized by concern, mod and purpose. Local files and the running singleplayer server remain separate contexts. Repeated placements share their actual document and draft.
- Keep existing JSON, properties, native TOML, Controls and operator-command owners. Retain strict domain validation, complete generation/shape reviews, stale-source refusal and explicit saved, staged, effective and failed outcomes. Existing filenames and generation identity remain unchanged.
- Apply Hoofprint zoom through its live owner and Wayfinder policy through the actual integrated server. Keep journal shortcuts on the same native source as the catalog. Preserve the native restart and new-world requirements of other settings.
- Use delegated native owners for Redstone Link GUI and Dynamic Waters. Preserve their exact supported fields and callbacks; a saved setting is not a claim that every downstream effect is already active.
- Keep search reporting bound to the requesting connection, captured origin, policy and job. Native operator commands remain available without a client configuration protocol.
- Present shader rebuilds as identified operations with explicit failure and retry. Keep each optional integration's startup selection, supported versions and physical side intact.

The release does not redesign terrain, change world identity or enable a remote forms protocol. See [verification](docs/development/verification.md#shared-settings-owners) for the qualified artifacts, native/pack checks and remaining platform limits.
